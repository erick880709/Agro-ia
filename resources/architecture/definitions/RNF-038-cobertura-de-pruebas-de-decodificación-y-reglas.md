# RNF-038: Cobertura de pruebas de decodificación y reglas

**Tipo:** Requerimiento no funcional
**Categoría:** Pruebas
**Fuente:** RFP-AGROIA-003 §7 (Requerimientos no funcionales)

## Descripción
Cobertura unitaria de decodificación y reglas con vectores propios, incluidos temperaturas negativas y saturaciones.

## Criterio medible / restricción concreta
100 % de vectores de prueba decodificados correctamente, incluida temperatura negativa.

## Impacto en la arquitectura
Los vectores propios evitan depender de ejemplos inconsistentes del manual (H-13).

## Notas del analista
No aplican — el RFP define el requisito de forma concreta.
