# RNF-037: Operación offline

**Tipo:** Requerimiento no funcional
**Categoría:** Operación offline
**Fuente:** RFP-AGROIA-003 §7 (Requerimientos no funcionales)

## Descripción
El firmware y la PWA conservan la idempotencia existente para operación sin conectividad.

## Criterio medible / restricción concreta
Idempotencia de ingesta sin duplicados.

## Impacto en la arquitectura
Heredado del buffer offline e idempotencia de RF-059.

## Notas del analista
No aplican — el RFP define el requisito de forma concreta.
