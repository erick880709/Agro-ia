# HU-01: Botón de micrófono con estados y nivel de audio

## Como
Productor o técnico de campo

## Quiero
Ver un botón de micrófono identificable junto al campo de texto del chat, con indicación visual de los estados y del nivel de audio

## Para
Saber cuándo puedo dictar y qué está ocurriendo en cada momento

## Criterios de Aceptación
- [ ] CA1: Se muestra un botón de micrófono identificable junto al campo de texto, apto para uso táctil en móvil.
- [ ] CA2: La interfaz informa los estados inactivo, grabando, procesando y error.
- [ ] CA3: Durante la captura se muestra un indicador visual del nivel de audio.
- [ ] CA4: El estado de grabación no se distingue solo por color (señal textual + etiquetas aria).
