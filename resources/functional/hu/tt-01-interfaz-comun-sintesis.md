# TT-01: Interfaz común de síntesis de voz

## Descripción
Definir e implementar un servicio de voz con operación única "texto → audio" para intercambiar motores sin tocar el chat.

## Criterios de Done
- [ ] Interfaz definida (entrada: texto limpio, voz, velocidad; salida: audio/streaming).
- [ ] El chat consume solo la interfaz, sin acoplarse a un motor.

## Dependencias
- Ninguna
