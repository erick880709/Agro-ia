# HU-03: Lectura automática y manual de respuestas

## Como
Productor o técnico de campo

## Quiero
Que las respuestas nuevas se lean automáticamente cuando la función esté activa, y poder leer cualquier respuesta con un botón de altavoz

## Para
Escuchar sin mirar la pantalla

## Criterios de Aceptación
- [ ] CA1: Las respuestas nuevas se leen automáticamente cuando la función está activa.
- [ ] CA2: Cada respuesta tiene un botón de altavoz para lectura manual (aunque la función esté apagada).
- [ ] CA3: Se informa el estado: preparando audio, reproduciendo y error.
