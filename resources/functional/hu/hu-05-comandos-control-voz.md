# HU-05: Comandos de control por voz

## Como
Productor o técnico de campo

## Quiero
Controlar el chat con los comandos “enviar”, “borrar”, “cancelar” y “repetir”, reconocidos solo cuando se pronuncian solos

## Para
Operar el chat sin tocar el teclado

## Criterios de Aceptación
- [ ] CA1: “Enviar” envía el texto actual del campo.
- [ ] CA2: “Borrar” y “Cancelar” limpian el campo de entrada.
- [ ] CA3: “Repetir” descarta la transcripción y reinicia la captura.
- [ ] CA4: Los comandos se reconocen únicamente si se pronuncian solos, nunca como parte de una pregunta.
