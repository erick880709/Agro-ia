# HU-05: Lectura natural del texto

## Como
Productor o técnico de campo

## Quiero
Que la lectura omita símbolos y formato y pronuncie bien las unidades agronómicas

## Para
Entender sin ruido de "ppm", "kg/ha" o marcas de Markdown

## Criterios de Aceptación
- [ ] CA1: No se pronuncian símbolos, enlaces, tablas ni formato.
- [ ] CA2: Las unidades se leen de forma natural ("kg/ha" → "kilos por hectárea").
