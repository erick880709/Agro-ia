# RF-028: Envío al servicio de chat existente

**Tipo:** Requerimiento funcional
**Fuente:** RFP-AGROIA-001 — Secciones 3, 4.1, 7 (RF-06), 9.2 y 11
**Prioridad:** Mandatoria (M)

## Descripción
Una consulta dictada y confirmada debe enviarse como texto al servicio de chat existente. La incorporación de voz no debe duplicar ni modificar la lógica del agente agronómico.

## Actores involucrados
- Productor / agricultor
- Técnico / extensionista
- Asesor agronómico existente

## Criterios de aceptación
- El envío usa el servicio de chat existente, sin duplicar la lógica del agente.
- La respuesta se presenta en texto dentro del chat.

## Dependencias / relacionados
- RF-014: Agente conversacional IA
- RF-027: Revisión y edición de la transcripción
- RT-016: Confirmación de arquitectura vigente
- RT-018: Integración con chat y transcripción

## Notas del analista
El RFP supone que el endpoint actual permanece estable; debe confirmarse en la fase inicial.
