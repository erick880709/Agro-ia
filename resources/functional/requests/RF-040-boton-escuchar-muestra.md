# RF-040: Botón "Escuchar muestra" de la voz

**Tipo:** Requerimiento funcional
**Fuente:** RFP-AGROIA-002 — Secciones 4.1, 6.1 y 7 (RF-03)
**Prioridad:** Mandatoria (M)

## Descripción
Junto al selector de voz, debe existir un botón "Escuchar muestra" que reproduzca una muestra de la voz seleccionada para que el usuario la pruebe antes de elegirla.

## Actores involucrados
- Productor / agricultor
- Técnico / extensionista

## Criterios de aceptación
- Al pulsar "Escuchar muestra" se reproduce un fragmento de ejemplo con la voz seleccionada.

## Dependencias / relacionados
- RF-039: Selector de voz
- RT-020: Interfaz común de síntesis

## Notas del analista
El RFP no define el texto de la muestra; se recomienda una frase corta con términos agronómicos (ej. pH, materia orgánica) para que el usuario evalúe la pronunciación técnica.
