# RF-066: Transparencia

**Tipo:** Requerimiento funcional
**Fuente:** RFP-AGROIA-003 §6 (Requerimientos, Épica E2)
**Prioridad:** No especificada

## Descripción
Cada reporte indica 'N de M lecturas válidas' y cuántas lecturas se excluyeron por cada motivo. Las lecturas excluidas siguen consultables en administración.

## Actores involucrados
Sistema de reportes, administrador

## Criterios de aceptación
Todo reporte con grado de evidencia y variables no medidas declaradas (§9).

## Dependencias / relacionados
RF-062; RF-084 (reporte).

## Notas del analista
Alineado con el principio 1: el valor crudo se conserva siempre, nada se borra.
