# RF-077: Contexto agronómico

**Tipo:** Requerimiento funcional
**Fuente:** RFP-AGROIA-003 §6 (Requerimientos, Épica E5)
**Prioridad:** No especificada

## Descripción
Registrar fecha de última fertilización, riego y lluvia (IDEAM o pluviómetro). Lecturas dentro de una ventana parametrizable posterior a fertilización o riego se marcan `valida_con_advertencia` y no se usan para clasificar fertilidad.

## Actores involucrados
Técnico de campo, motor de calidad

## Criterios de aceptación
No especificados en el RFP — definir con el cliente.

## Dependencias / relacionados
RF-062; RF-077.

## Notas del analista
H-11: fertilización/riego/lluvia elevan CE y NPK en horas.
