# RF-083: Recomendación de muestreo de laboratorio

**Tipo:** Requerimiento funcional
**Fuente:** RFP-AGROIA-003 §6 (Requerimientos, Épica E6)
**Prioridad:** No especificada

## Descripción
Cuando el sensor detecta anomalías o variables en frontera, el sistema sugiere puntos concretos de muestreo para laboratorio, alineado con la comisión de muestreo en grilla y el módulo de costos.

## Actores involucrados
Motor de reglas, orquestador, módulo de costos

## Criterios de aceptación
No especificados en el RFP — definir con el cliente.

## Dependencias / relacionados
RF-068 (frontera); RF-081.

## Notas del analista
Convierte el sensor en herramienta de priorización de muestreo.
