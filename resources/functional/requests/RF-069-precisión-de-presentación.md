# RF-069: Precisión de presentación

**Tipo:** Requerimiento funcional
**Fuente:** RFP-AGROIA-003 §6 (Requerimientos, Épica E3)
**Prioridad:** No especificada

## Descripción
pH se muestra a 0,1 (±0,3), N/P/K redondeados a su incertidumbre (decenas de mg/kg), humedad a 1 % y CE a 0,01 dS/m. Se muestra siempre el intervalo, no solo el valor puntual.

## Actores involucrados
Sistema de reportes, frontend

## Criterios de aceptación
No especificados en el RFP — definir con el cliente.

## Dependencias / relacionados
RF-067; RF-084.

## Notas del analista
H-07: evitar que el usuario interprete diferencias que son ruido.
