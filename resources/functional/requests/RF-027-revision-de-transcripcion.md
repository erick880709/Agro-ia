# RF-027: Revisión y edición de la transcripción

**Tipo:** Requerimiento funcional
**Fuente:** RFP-AGROIA-001 — Secciones 3, 4.1, 6, 7 (RF-05) y 11
**Prioridad:** Mandatoria (M)

## Descripción
Al completarse la transcripción, el sistema debe insertarla en el campo de entrada del chat para que el usuario pueda revisarla y editarla. La transcripción no debe enviarse automáticamente.

## Actores involucrados
- Productor / agricultor
- Técnico / extensionista

## Criterios de aceptación
- La transcripción aparece en el campo de texto y se puede editar.
- No se envía hasta que el usuario confirme el envío.

## Dependencias / relacionados
- RF-026: Transcripción de voz en español
- RF-028: Envío al servicio de chat existente

## Notas del analista
El RFP prescribe la revisión antes del envío; no define conservación de borradores ante navegación o cierre de sesión.
