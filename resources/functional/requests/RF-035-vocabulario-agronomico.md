# RF-035: Reconocimiento de vocabulario agronómico

**Tipo:** Requerimiento funcional
**Fuente:** RFP-AGROIA-001 — Secciones 7 (RF-13) y 11
**Prioridad:** Deseable (D)

## Descripción
La transcripción debe reconocer términos agronómicos comunes, incluidos materia orgánica, pH, fósforo, nitrógeno, cultivares y los nombres de los cultivos disponibles en el catálogo.

## Actores involucrados
- Productor / agricultor
- Técnico / extensionista
- Catálogo de cultivos de AgroIA

## Criterios de aceptación
- Se valida la precisión con vocabulario agronómico en pruebas.
- El conjunto de términos y el umbral de precisión aceptable se acuerdan para las pruebas.

## Dependencias / relacionados
- RF-026: Transcripción de voz en español
- RF-009: Catálogo de cultivos

## Notas del analista
El RFP no define un glosario, una medida de precisión ni el mecanismo técnico para mejorar el reconocimiento.
