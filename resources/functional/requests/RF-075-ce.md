# RF-075: CE

**Tipo:** Requerimiento funcional
**Fuente:** RFP-AGROIA-003 §6 (Requerimientos, Épica E4)
**Prioridad:** No especificada

## Descripción
Caracterizar el sensor con soluciones patrón (p. ej. 1413 µS/cm), normalizar a 25 °C si el sensor no lo hace, y calibrar CE aparente ↔ CEe / CE 1:5 por suelo para evaluar salinidad.

## Actores involucrados
Agrónomo, técnico de campo

## Criterios de aceptación
R² ≥ 0,8 frente a CE 1:5 o CEe (§9).

## Dependencias / relacionados
RF-071; RF-058 (unidades).

## Notas del analista
H-06: CE sin exactitud declarada y sin compensación de temperatura.
