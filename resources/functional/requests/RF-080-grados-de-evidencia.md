# RF-080: Grados de evidencia

**Tipo:** Requerimiento funcional
**Fuente:** RFP-AGROIA-003 §6 (Requerimientos, Épica E6)
**Prioridad:** No especificada

## Descripción
Clasificación de evidencia: A = laboratorio vigente (<90 días); B = sensor con calibración local vigente que cumple metas; C = sensor sin calibración local (indicativo); D = estimado SIG o modelo. Cada dato, clasificación y recomendación exhibe su grado.

## Actores involucrados
Motor de reglas, orquestador, reportes

## Criterios de aceptación
Todo reporte con grado de evidencia y variables no medidas declaradas (§9).

## Dependencias / relacionados
RF-072 (equivalencia); RD-012 (UI).

## Notas del analista
Eje central del RFP: limitar qué se puede concluir con cada dato.
