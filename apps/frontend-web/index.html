🔗 API de sensores — simulador de trama

Conexión real de los sensores: POST /api/sensor. El firmware envía un JSON con device_id obligatorio y estos campos: ph (0–14), nitrogen, phosphorus y potassium (ppm), conductivity (µS/cm), humidity (% HR ambiente, DHT22) y temperature (°C). Si el sensor mide suelo, envía soil_humidity y soil_temperature (se guardan como humedad y temperatura del suelo). finca_id (UUID) asocia el dispositivo a tu finca, y pos_x/pos_y registran el punto de muestreo para el mapa de calor. Si el device_id no está registrado, el API lo auto-registra. Pega una trama y pruébala:
